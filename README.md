# Algoritmos em Java

Repositório dedicado aos meus estudos de lógica de programação e algoritmos utilizando Java.

## Objetivo

Fortalecer minha base de programação por meio da resolução de exercícios práticos, desenvolvendo raciocínio lógico, capacidade de decomposição de problemas e domínio dos fundamentos da linguagem Java.

## Conteúdos estudados

* Variáveis
* Tipos de dados
* Operadores
* Estruturas condicionais
* Estruturas de repetição
* Métodos
* Arrays
* Strings
* Algoritmos
* Estruturas de dados
